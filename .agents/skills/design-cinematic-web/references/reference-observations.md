## Synthesis across all four references

Shared principles: a strong focal subject; typography with distinct scales; quieter navigation/metadata; continuity between scenes; contrast between immersive and readable sections; media-led identity.

Variable choices: serif versus sans, warm versus cool, light versus dark, organic versus geometric detail, image-led versus simulated environments. Therefore the system must select visual grammar per brand rather than require neon, grids, or 3D on every site.

All references favor promotional presentation. They are not evidence for effective checkout, dense analytics, accessibility, load performance, SEO, or responsive behavior. Guidance for these areas in other references is implementation design guidance, not observations from these clips.
